# Contributing to Water-Chan

Thank you for your interest in improving this project! We welcome your help.

## How to Contribute

### 1. Reporting Bugs
- Search open [GitHub Issues](https://github.com/AzuritilDev/Water-Chan/issues) to avoid duplicates.
- Open a new issue if yours is undocumented.
- Provide clear steps to reproduce the bug.

### 2. Submitting Changes
- Fork this repository to your account.
- Create a new branch for your specific fix or feature.
- Commit your changes with descriptive commit messages.
- Submit a Pull Request (PR) targeting the `main` branch.
Please, make sure to test the application after you've done changes before you submit the Pull Request.

## Code of Conduct
See [CODE_OF_CONDUCT.md](.github/CODE_OF_CONDUCT.md). Please be kind, respectful, and clear in all communication.
